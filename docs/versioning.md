# Document Versioning Policy

**Date:** 2026-09-25

## Status Labels

- Draft
- Working
- Review
- Approved
- Superseded

## Version Pattern

- Vision/strategy docs: `v0.x`
- Implementation-ready baseline: `v1.0`
- Incremental updates: `v1.1`, `v1.2`, ...

## Rules

1. Each document must include status, version, and date.
2. Breaking scope changes require a version bump.
3. Superseded docs must link to their replacement.
4. ADR references should be updated when decisions change.
