# 02 — POC Results and MVP Specification

**Document status:** Transition Spec  
**Version:** v0.5 (draft target)  
**Date:** 2026-09-25

## Purpose

Capture POC outcomes and convert findings into concrete MVP requirements.

## Required Sections

1. **POC Outcomes**
   - what worked
   - what failed
   - where risk remains
2. **Capability Decisions**
   - keep / change / remove
3. **MVP Scope Lock**
   - must-have vs should-have
4. **Schema Freeze Candidates**
   - agent manifest v0.1
   - model API v0.1
   - tool capability API v0.1
   - event/artifact schema v0.1
5. **Security Updates**
   - threat model adjustments
   - policy gaps and controls
6. **Delivery Plan**
   - milestones
   - acceptance criteria

## MVP Gate

MVP implementation begins only after:

- POC exit criteria are met
- MVP scope is locked
- core interfaces are specified
- risks have mitigation owners
